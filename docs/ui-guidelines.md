# UI Guidelines

The Atria desktop interface is quiet, compact, and stable.

- Use a fixed-width vertical rail.
- Use a fixed-width workspace explorer.
- Use a fixed-width right block sidebar.
- Keep the main editor and preview area stable across content types.
- Avoid hero sections, upload dashboards, API instructions, marketing text, and large card walls.
- Keep source labels subtle: `human`, `ai`, `timeline`.
- Place destructive and structural actions in context menus or compact affordances.
