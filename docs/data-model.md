# Data Model

Atria stores human-authored pages, AI-created HTML artifacts, timeline summaries, projects, assets, and settings as file-system-first data.

Core content sources:

- `human`: user-created pages and timeline notes.
- `ai`: HTML artifacts and AI-generated summaries.

Core content types:

- Page: editable block document.
- Artifact: AI-created HTML report with metadata and asset directory.
- Timeline summary: daily, weekly, or monthly block document.
- Project: task line grouping pages, artifacts, and summaries.
