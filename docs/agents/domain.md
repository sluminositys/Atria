# Domain Docs

Atria is a single-context repository.

Before architecture, diagnosis, or test-design work:

- Read `CONTEXT.md` at the repository root.
- Read relevant decisions under `docs/adr/`.
- Use the exact domain vocabulary defined in `CONTEXT.md`.
- Surface conflicts with an existing ADR instead of silently overriding it.

Add a domain term only when it is specific to Atria. Add an ADR only for a consequential decision with a real trade-off.
