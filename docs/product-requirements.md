# Product Requirements

Atria is a local-first desktop workspace for collecting AI-generated HTML reports and human-authored block notes. It should feel like an Obsidian-style vault with a Notion-like editing surface, not a CMS, dashboard, admin panel, or public blog.

First-stage acceptance:

- Fixed rail, file tree, main editor/preview, and block sidebar.
- Human pages support editing, block insertion, deletion, and autosave.
- AI artifacts preview in isolated iframes.
- Multiple tabs can be opened and closed.
- AI-created and human-created content are visually distinguishable.
- Timeline and project organization are first-class.
- MCP server can write and query the same workspace through semantic tools.
